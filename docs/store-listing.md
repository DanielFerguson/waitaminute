# Chrome Web Store listing copy

## Short description

Add a moment of intention before distracting websites.

## Description

WaitAMinute adds a small pause before websites you choose. Use a soft block with a countdown or quick maths question when you want a chance to reconsider, or a hard block when you need a clearer boundary.

- Block domains all day or on your own schedule.
- Keep rules synced through Chrome Sync.
- See local-only statistics for your pauses and bypasses.
- Export and import your configuration.

WaitAMinute does not use analytics or advertising. Read the privacy policy before installing.
